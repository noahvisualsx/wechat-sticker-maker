# 真人表情包严苛质检与人体解剖红线标准（Strict Quality & Anatomy Red-Line Specification）

> **适用范围**：所有由 Codex / Claude Code 内置生图或云端图像模型（OpenAI `gpt-image-1`、Gemini Image、Doubao Seedream 等）生成的真人单人表情包（`expressions`）、真人双人互动表情包（`duo`）、真人热梗图（`memes`）、真宠实拍表情包（`pet`）及 `2×2` 动态多帧序列图（Sprite Sheet）。
>
> **执行原则**：**一票否决制（Zero-Tolerance Gate）**。任何一张原图（`work/raw_static/*_raw.png`、`work/raw_gif/*_sheet_raw.png`）或成品图只要触发任一 **P0 红线缺陷**，**严禁进入打包交付阶段**，必须立即携带针对性纠偏约束（`[CRITICAL RETRY CORRECTION]`）重新生成并通过二次质检。

---

## 一、八维严苛质检红线（8-Dimension Red-Line Criteria）

### 红线 1：肢体与手部解剖拓扑守恒（Limb & Hand Topology Hard Lock）— 【P0 一票否决】

AI 图像模型在处理“参考图原姿势 + 新手势指令”时，最容易发生**原图残留肢体与新增手势叠加**的解剖学幻觉。必须逐张放大核验以下铁律：

1. **手臂与手掌数量绝对上限**：
   - **单人贴纸（Single）**：画面中可见手臂 **严格 `≤ 2` 条**（左肩 1 条、右肩 1 条），可见手掌 **严格 `≤ 2` 只**。
   - **双人互动（Duo）**：画面中可见手臂总数 **严格 `≤ 4` 条**（每人左 1 + 右 1），可见手掌总数 **严格 `≤ 4` 只**。
2. **严禁“同肩双臂分裂 / 第三只手”（Same-Shoulder Dual-Arm Split — 最高发翻车点）**：
   - **典型故障形态**：人物穿短袖/针织衫时，袖口向下自然垂落一条手臂贴在身体侧边，**与此同时**同一侧肩膀后方或长发掩映处又向上探出第二条裸露手臂去摸头顶、撩头发、比耶或托腮（即单侧肩膀长出 2 条手臂，全身出现 3 条手臂）。
   - **强制解剖学铁律**：当某一侧手抬高做动作（摸头、撩发、捂嘴、比心、拿手机）时，**该侧肩膀与衣袖必须同步向上抬起衔接该手臂**，原侧下方**绝对禁止**同时残留自然下垂的袖管或手臂。
3. **严禁“单人三手动作冲突”（Impossible Multi-Prop Gesture）**：
   - 单人手里握持道具（如单手举手机拍照、端奶茶杯、举应援棒）时，另一只手至多只能做单手动作（如单手挥手、单手捂嘴笑）；**严禁出现“双手合十鼓掌 + 第三只手举手机”**等违反人类生理结构的姿势。
4. **严禁“幽灵断手 / 橡胶绕背长臂”（Disembodied Hands & Rubber Arms）**：
   - 肩头、脸颊、腰侧、胸前出现的所有手掌，必须能清晰追溯到唯一合理的衣袖与肩膀归属；严禁出现无手腕连接的悬浮断手（Floating Severed Hand），严禁手臂像橡皮筋一样从背后绕出两倍长度去捏对方外侧脸颊。
5. **手指数量与腕部关节自然度**：
   - 清晰露出的手掌必须符合正常人类 **5 指结构（1 拇指 + 4 手指，允许自然透视遮挡）**；严禁 6 指/7 指、章鱼触手状分叉融化指、手掌正反面装反（拇指朝外侧反折）或手腕 180° 骨折扭曲。

---

### 红线 2：面部几何与头身骨相比例锁定（Craniofacial Proportion & Aspect Lock）— 【P0 一票否决】

1. **严禁纵向拉长变形（No Vertical Face Elongation / "Horse-Face" Distortion）**：
   - 人脸的**三庭五眼比例**与**面宽/面高比（Facial Width-to-Height Ratio, 约 `1 : 1.20 ~ 1.32`）**必须与输入参考照严格一致（允许自然透视俯仰，但正面/微侧面宽高比偏差不得超过 `±12%`）。
   - **严禁中庭（眉心至鼻底）、鼻梁、人中或下巴被纵向拉长**导致脸型变窄变长（俗称“马脸/拉面脸变形”）。
2. **严禁双人同框横向挤压（No Horizontal Squishing in Duo Frames）**：
   - 双人正方形构图中，两人应采用 **微侧身 `15%–25%` 自然前后叠肩站位（Comfortable Overlapping Shoulders）**，严禁把两个正面宽肩人物生硬水平压缩塞进方框，导致两张脸同步变窄拉长。
3. **严禁非鱼眼风格下的边缘透视畸变与五官坍塌**：
   - 除显式指定 `real-fisheye-y2k` 大头鱼眼风格外，一律采用等效 `50mm–85mm` 标准人像镜头透视，严禁广角边缘把额头或下颌拉歪。
   - 双眼瞳孔焦点必须自然对齐同一视线方向，严禁高低眼坍塌、大小眼畸变、嘴角融化或牙齿粘连成白条。

---

### 红线 3：真人身份与骨相 100% 锁定（Identity & Outfit Fidelity）— 【P0 一票否决】

- 脸型轮廓（下颌角、颧骨、下巴尖圆度）、眼型与双眼皮褶皱、鼻梁与鼻翼、唇珠与唇厚、发际线与刘海分缝、原图服装款式与颜色必须忠实还原参考照本人。
- 严禁换成千篇一律的 AI 网红模板脸，严禁把真人重绘成 2D 动漫、韩漫厚涂、Q 版插画、3D 盲盒公仔或熊猫头套脸。

---

### 红线 4：100% 真实人类五官与肤质（Zero 2D Cartoon Facial Symbols）— 【P0 一票否决】

- **眼球红线**：哪怕表现“晕倒、震惊、崇拜、眼冒金星、心碎”，也必须通过**真实人类眼轮匝肌、眼神失焦、自然半闭眼、瞪大双眼或真实泪光**来表达；**绝对禁止**在眼球上画螺旋蚊香圈（`@_@`）、星星贴纸、爱心贴纸、人民币/金币符号或无瞳孔纯白漫画眼。
- **皮肤红线**：保留真实人像皮肤质感与光影过渡；严禁在脸上直接画漫画黑线阴影、泥巴涂鸦裂纹或大块矢量腮红贴片。

---

### 红线 5：真透明 Alpha 通道与纯净抠图（True Alpha & Zero Baked Checkerboard）— 【P0 一票否决】

1. **绝对禁止“画入式灰白棋盘格”（Zero Baked-In Checkerboard Grid）**：
   - AI 原图背景必须为 **原生 RGBA 真透明（`alpha = 0`）** 或 **纯平均匀单色白底（`#FFFFFF`，无阴影渐变）**。
   - **严禁图像生成模型将 Photoshop 灰白相间透明棋盘格（`#FFFFFF` / `#CCCCCC` 方格阵列）直接渲染进 RGB 像素**！一旦检测到边缘或背景存在周期性灰白方格，立即判定 `FAIL (baked_checkerboard)` 并打回重绘。
2. **零悬浮残肢/噪点孤岛（Zero Disconnected Alpha Islands）**：
   - 抠图后的单张原图（未叠加气泡/文字前）必须为干净连贯的人物主体轮廓；严禁背景中残留未抠净的悬浮手掌碎块、孤立色块或 AI 自行偷画的 `?`、`!`、`zzz`、音符等涂鸦符号。

---

### 红线 6：自然半身景别与边缘完整性（Framing & Edge Integrity）— 【P1 严重缺陷】

1. **胸上 / 腰上黄金半身景别（Chest-Up / Waist-Up Portrait）**：
   - 表情包在手机聊天窗仅以 `120px–240px` 显示，人物必须采用**胸上或腰上半身特写**，主体包围盒占画布面积建议 `22%–78%`，头部高度占主体总高度 `28%–52%`，确保缩略图下五官神态一目了然。
   - **严禁缩成全身蚂蚁小人**（如全身跪地磕头、全身远景站立导致人脸不足 30px）。
2. **无背景道具自洽性**：
   - 在透明无背景贴纸中，严禁出现“双手平推透明空气墙（无墙壁咚）”或“悬空坐空气椅”等失去环境依托后显得诡异僵硬的姿势。
3. **边缘完整留白**：
   - 头顶发丝、高举的手指或道具顶端必须保留至少 `2%–4%` 画布安全边距，严禁头顶或手指在画布最顶端（`y = 0`）被一刀切平截断（仅允许人物腰部/胸口底边自然裁切并由模切白边封口）。

---

### 红线 7：`2×2` 动态四宫格序列一致性（Sprite Sheet Quadrant Lock）— 【P1 严重缺陷】

- 四宫格（Top-Left / Top-Right / Bottom-Left / Bottom-Right）内 4 帧人物的**头身比例、脸宽脸长、服装领口细节与下半身基准线**必须保持一致，4 格主体高度极差不得超过 `32%`。
- 四格之间必须留有干净透明/纯白分隔带，**严禁手臂、发丝或道具跨过十字中线刺入相邻象限**（`sprite_cross_bleed`）。
- 4 帧必须呈现真实连贯的人类动作变化（挥手角度、眨眼开合、微表情递进），严禁 4 格完全静态复制（`sprite_static_duplicate`）。

---

### 红线 8：纯净单语种与零 AI 光栅乱码字（Single-Language & Zero Raster Text）— 【P0 一票否决】

- **AI 原图零文字**：严禁图像模型在原图画面、背景、衣服新增标牌或气泡里自行绘制任何中英日韩文字或水印（模型手绘汉字极易缺笔少画成鬼画符）。
- **整包 100% 单一语种**：所有底部花字、对话气泡、梗图组件及展示海报均由 Python 排版引擎确定性渲染，严格使用 `--language` 指定的唯一语种，零跨语种混杂、零字体缺字方框（`☒` / `.notdef`）。

## 二、标准缺陷码与自动纠偏映射表（Defect Codes & Corrective Retry Rules）

`wechat-sticker-maker audit` 与 `StickerOrchestrator` 使用以下标准缺陷码进行自动拦截与 Prompt 纠偏重试：

| 缺陷码 (`defect_code`) | 级别 | 触发条件 | 自动注入纠偏指令 (`build_corrective_retry_prompt`) |
|---|---|---|---|
| `baked_checkerboard` | `FAIL` | 边缘/背景检出灰白交替棋盘格像素或抠图后周期性灰块残留 | 强制纯平 `#FFFFFF` 单色白底或真 RGBA `alpha=0`，严禁绘制灰白透明方格阵列 |
| `third_hand_or_extra_limb` | `FAIL` | VLM 或人工复核检出单人 `>2` 臂/手、双人 `>4` 臂/手、同肩双臂分裂 | 强制左肩 1 臂 + 右肩 1 臂；抬手摸头时该侧衣袖必须同步上提，严禁原侧下方再画垂落衣袖/手臂 |
| `stretched_or_warped_face` | `FAIL` | VLM 检出中庭/下巴纵向拉长、马脸变形，或程序检出极端窄长高宽比 (`vertical_stretch`) | 锁定参考照原生面部宽高比（约 `1:1.25`），严禁拉长鼻梁/人中/下巴；双人自然叠肩 `20%` 严禁横向挤压 |
| `floating_island` | `FAIL`/`WARN` | 原图抠图后存在与主体分离的悬浮手掌/残片/涂鸦文字孤岛 (`0.4%–15%` 面积) | 严禁悬浮断手、飞散碎片或画入式 `?`/`!` 文字涂鸦，保持单一连贯人物轮廓 |
| `tiny_subject` | `FAIL`/`WARN` | 主体占比过小 (`bbox < 15%` 或 `fill < 6%`)，缩成全身小人 | 强制切回胸上/腰上近景半身人像（头部占画面高度 `32%–45%`），严禁全身远景 |
| `hard_edge_clip` | `WARN`/`FAIL` | 原图顶端或左右边缘大面积实心截断头顶/手掌 | 缩小镜头焦段或微调构图，给头顶与抬起的手掌预留至少 `5%` 顶部安全空白 |
| `cartoon_eyes_or_drift` | `FAIL` | 蚊香眼 `@_@`、星星贴纸眼、2D 动漫化或换脸 | 强制 100% 真实摄影眼球虹膜、皮肤毛孔与本人骨相 |
| `sprite_quadrant_mismatch` | `FAIL` | `2×2` 四宫格某格空白、跨中线穿帮或四格人物忽大忽小 | 强制 `2×2` 严格四等分居中对齐、统一半身比例、十字中线留空不越界 |

## 三、Codex / Claude Code 强制执行质检流程（Mandatory Agent QA Workflow）

当在 Codex、Claude Code 或本地脚本中生成表情包时，**严禁生成完直接交付**，必须严格执行以下 4 步质检闭环：

1. **生成前注入解剖与比例硬锁**：
   始终调用 `build_static_prompt` / `build_duo_static_prompt` / `build_sprite_sheet_prompt` 生成带 `[ANATOMY & FACIAL PROPORTION HARD LOCK]` 与 `[CLEAN BACKGROUND LOCK]` 的提示词。
2. **生成后立即运行严苛质检并输出 `2×` 局部放大质检单**：
   ```bash
   wechat-sticker-maker audit -o <output_dir> --strict
   ```
   （若已配置 `OPENAI_API_KEY` 或 `GEMINI_API_KEY`，追加 `--vlm` 开启多模态视觉解剖学自动判卷。）
3. **人工 / Agent 必看 `qa/strict-audit-sheet.jpg`（2× 放大三联检视卡）**：
   打开 `<output_dir>/qa/strict-audit-sheet.jpg`，逐张核对三联放大视图（全身撞色底检视 + **2× 脸部与双肩放大特写** + **2× 手部与衣袖衔接特写**），逐项默念清点：
   - **数肩膀与袖口**：左边肩膀几条手臂？右边肩膀几条手臂？有没有“袖子往下垂 + 背后又伸出一只光胳膊摸头”？
   - **看脸宽与中庭**：对比参考照，脸有没有被纵向拉成细长条？五官眼神是否自然真实？
   - **看背景与边缘**：撞色底上有没有残留灰白棋盘格、白边脏块或断手孤岛？
4. **不合格项精准纠偏重绘**：
   凡发现任一红线问题，立即使用纠偏指令单张重绘（`wechat-sticker-maker regenerate -j <output_dir>/job.json --item <id> --defect third_hand_or_extra_limb,stretched_or_warped_face` 或在 Codex 中附带 `audit` 输出的 `[CRITICAL RETRY CORRECTION]` 重新出图），直至全部 `PASS`。
