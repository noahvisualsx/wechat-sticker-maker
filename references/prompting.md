# Prompting Reference

## 结构化提示词分块设计

为确保表情包风格一致且角色不漂移，提示词由 5 个结构块拼装而成：

1. `[IDENTITY LOCK]`
   - 描述角色身份核心事实与不可变属性。
   - 引用主锚点图与源照片，强调“不要重新设计角色”。
2. `[STYLE LOCK]`
   - 统一步骤：Q版马卡龙色调贴纸风格、圆润粗描边、柔和平光。
   - 单主体居中，透明背景。
3. `[ACTION]`
   - 对应预设中的特定表情与身体微动作（如：双手捂脸、小幅歪头）。
4. `[COMPOSITION]`
   - 正方形画布，底部预留文字安全区，模型严禁自主在栅格图中写文字。
5. `[NEGATIVE]`
   - 负面词约束：无水印、无拼贴画、无背景杂色、无多余肢体、无模型自带文本。
