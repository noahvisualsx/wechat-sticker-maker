# Animation Policy Reference

## 1. 动图生成双路线策略
- **路线 A：原生 GIF 生成 (Native GIF)**
  - 依赖 GPT Image 2.6 生成端点 (`/v1/images/generations`，`output_format: "gif"`)。
  - 特点：速度快、单次请求生成完整循环。
  - 适用：原创卡通角色或通用动物表情；当原照片身份严格保留优先时，若原生生成产生身份漂移，需自动降级到路线 B。
- **路线 B：关键帧合成 (Keyframe Composition，默认推荐)**
  - 基于角色锚点图（Master Anchor）进行局部动作逐帧演化，或分层动作插值合成。
  - 特点：最高程度继承源图身份，角色五官和体态无抖动漂移。
  - 适用：真人照片、特色宠物（斑纹精确）等强身份约束场景。

## 2. 帧数与节奏规范
- 默认帧数：8 帧。
- 默认单帧时长：180ms（总周期约 1.44s）。
- 循环模式：`loop=0`（无限循环），首尾帧动作必须平滑无跳变。
- 关键部位不动原则（Stationary Parts）：发型/毛色花纹、服装轮廓、身体基准坐标在循环中保持稳定。

## 3. GIF 透明度与调色板
- 采用 1-bit 透明索引色处理，防止透明边缘黑边/灰边。
- 使用统一调色板量化（Quantize / Adaptive Palette）与 `disposal=2`，避免前后帧残留鬼影。
